# Electric Circuits Notes and Practice Problems
*By Cooper McAllister*

This repository contains notes and example problems for the Electric Circuits or Intro to Circuits classes. I initially created these documents while I was leading Supplemental Instruction sessions in Spring 2026. There are over 80 pages in total. 
**These documents will be updated throughout the semester. The most recent version can always be pulled from this repo.**

## Organization
The files are split into two folders, "Practice Problems" and "Study Notes". Within each folder, the files are numbered by topics, with matching numbers in both folders. For example, P1 and R1 both cover Definitions and Units. (I think R stands for Resource.)

## Usage
These documents are intended to be used by anyone who is taking a circuits class or is interested in circuits. I've attempted to explain everything in my own words in the best way I know how, so that a student who is struggling with a concept might succeed after seeing it presented in a different way.
These files do not fall under any license and may be used, distributed, and modified at will. I only ask that you credit me if you do use them for your own work.

## LaTeX
I used LaTeX, with TeXworks software, to create these documents. I learned the language on my own and did not use AI in the creation of these documents. I used several additional packages, such as circuitikz, which will need to be installed for anyone wanting to build the pdfs from the source code.
